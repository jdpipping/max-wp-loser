# Results Layout

- `figures/` holds generated figures that are shared across deliverables.
- `tables/manuscript/` contains the canonical dyadic-bootstrap results, validation output, robustness summaries, generated TeX macros, frozen-data manifest, and session information.
- `logs/` is for optional saved run logs; it is intentionally empty by default.
- Large row-level fixed-clock and first-crossing intermediates are reproducible but intentionally ignored.
